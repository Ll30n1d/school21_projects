# Задание 1: Скрипт сбора информации о дистрибутиве

## Условие задания

Написать bash-скрипт `get_all_info.sh`, который при запуске от root собирает информацию о системе:
1. Установленные пакеты
2. Запущенные процессы
3. Открытые порты
4. Устанавливает пакеты `cowsay` и `sl`
5. Версию ядра и ОС
6. Записывает всё в файл `info` и сжимает в архив `OS_RESULT.tar`

---

## Разбор кода по пунктам

### 1. Проверка прав root

```bash
if [ "$EUID" -ne 0 ]; then
  echo "ERROR: скрипт должен быть запущен от имени root." >&2
  exit 1
fi
```

`$EUID` — переменная окружения, хранящая effective UID пользователя. У root он равен `0`. Если это не так — скрипт выводит ошибку в `stderr` (`>&2`) и завершается с кодом `1`.

---

### 2. Подготовка переменных

```bash
INFO_FILE="info"
ARCHIVE_NAME="OS_RESULT.tar"
```

Имена вынесены в переменные для удобства изменения в одном месте.

```bash
echo "=== Сбор системной информации ===" > "$INFO_FILE"
```

Оператор `>` перезаписывает файл — если `info` уже существовал, он будет очищен. Далее везде используется `>>` (дописывание).

---

### 3. Установленные пакеты

```bash
echo -e "\n--- Установленные пакеты (20шт) ---" >> "$INFO_FILE"
pacman -Q | head -n 20 >> "$INFO_FILE"
```

- `pacman -Q` — список установленных пакетов в Arch-подобных дистрибутивах.
- `head -n 20` — ограничение вывода первыми 20 строками.

---

### 4. Запущенные процессы

```bash
echo -e "\n--- Запущенные процессы (первые 10 процессов) ---" >> "$INFO_FILE"
ps aux | head -n 10 >> "$INFO_FILE"
```

- `ps aux` — вывод всех процессов системы (`a` — все пользователи, `u` — формат с user-ориентированными колонками, `x` — без терминала).
- `head -n 10` — первые 10 строк.

---

### 5. Открытые порты

```bash
echo -e "\n--- Открытые порты (20шт) ---" >> "$INFO_FILE"
ss -tuln | head -n 20 >> "$INFO_FILE"
```

- `ss -tuln` — утилита для просмотра сетевых соединений:
  - `-t` — TCP
  - `-u` — UDP
  - `-l` — только слушающие (listening)
  - `-n` — числовые порты (без резолва имён)
- `head -n 20` — ограничение вывода.

---

### 6. Установка пакетов cowsay и sl

```bash
pacman -S --noconfirm cowsay sl
```

- `-S` — установка пакета (sync/install).
- `--noconfirm` — не спрашивать подтверждения.
- `cowsay` — выводит текст «устами коровы».
- `sl` — «паровозик», который едет по экрану при опечатке `ls` → `sl`.

---

### 7. Версия ядра и ОС

```bash
echo -e "\n--- Версия ОС и Ядра ---" >> "$INFO_FILE"
uname -a >> "$INFO_FILE"
if [ -f /etc/os-release ]; then
    cat /etc/os-release >> "$INFO_FILE"
fi
```

- `uname -a` — информация о ядре: имя, версия, дата сборки, архитектура, hostname.
- `/etc/os-release` — стандартный файл дистрибутива (содержит `NAME`, `VERSION`, `ID`, `PRETTY_NAME` и т.д.). Проверка `-f` защищает от ошибки на системах, где файла нет.

---

### 8. Архивация

```bash
tar -cvf "$ARCHIVE_NAME" "$INFO_FILE"
```

- `-c` — create (создать архив).
- `-v` — verbose (показать процесс).
- `-f` — file (имя архива).

Создаётся `OS_RESULT.tar`, содержащий файл `info`.

---

## Итоговый результат

После запуска `sudo ./get_all_info.sh`:

```
OS_RESULT.tar   — архив с файлом info
info            — системная информация
```

Проверить содержимое архива:

```bash
tar -tf OS_RESULT.tar
# info
```
