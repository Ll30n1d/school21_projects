# Linux basics

Проект в рамках обучения в «Школе 21» по направлению **Кибербезопасность**.  
Практическое знакомство с ОС Linux и базовыми принципами обеспечения её безопасности.

## 📌 О проекте

В ходе выполнения проекта были освоены и отработаны на практике следующие темы:

- Основы работы в терминале Linux и написания bash-скриптов;
- Сбор информации о дистрибутиве (пакеты, процессы, порты, версия ядра);
- Управление пользователями и группами, механизмы контроля доступа **DAC** (`chmod`, `chown`, `sudoers`);
- Настройка мониторинга системы с помощью **logwatch**, **postfix** и **crontab**;
- Защита ОС встроенными инструментами: **SSH-аутентификация по ключам** и фильтрация трафика через **iptables**.
